# 用例库质量分析师

针对本项目测试用例库的质量分析技能，帮助 NPC 评估用例资产的质量、去重与覆盖情况。

## 适用场景

- 用例库整体健康度评估
- 重复用例检测与去重建议
- 覆盖率盲区识别（未覆盖的业务分支）
- 用例冗余 / 废弃清理建议
- 新功能测试用例补全规划

## 分析维度

### 1. 用例健康度
- 用例总数、有效数、废弃/停用数
- 评审状态分布（待评审 / 已通过 / 已驳回）
- 用例关联模块/需求覆盖情况
- 历史执行通过率

### 2. 重复检测
- 相同接口 / 相同输入输出的用例
- 近似重复（仅参数微调）
- 用例标题 / 步骤高度相似的冗余

### 3. 覆盖率盲区
- 对照后端路由与前端调用，找出未覆盖的接口
- 分析业务分支（异常、边界、权限）未覆盖场景
- 结合 `test-case-generator` 生成补测用例

### 4. 用例质量建议
- 断言语义是否明确
- 前置条件是否完整
- 数据是否独立可重跑（幂等性）
- 用例粒度是否合理（过大难定位、过小维护成本高）

## 分析流程

1. 统计用例库基础数据（数量、状态分布）
2. 扫描用例内容做重复与冗余分析
3. 对照后端路由做覆盖盲区分析
4. 输出质量报告：健康度评分、问题清单、优化建议

## 项目约定

- 用例库位于 `app/cases/`，支持功能用例与接口用例
- 用例状态：active / archived / trash（软删除）
- 用例含依赖、版本、变更记录（`loadDependencies` / `loadVersions` 等）
- 与 `app/reports/` 报告模块联动，可分析历史执行结果

## ✅ 验收标准

- [ ] 统计口径明确（用例总数、状态分布、模块分布），数据可复现
- [ ] 重复/冗余用例按「内容相似度 + 覆盖目标重合」两个维度判定，不靠标题猜测
- [ ] 覆盖盲区对照后端路由清单得出，标注未覆盖的具体路由
- [ ] 输出健康度评分与 Top N 待优化清单
- [ ] 建议项可落地（能具体到合并/删除/补测哪些用例）
