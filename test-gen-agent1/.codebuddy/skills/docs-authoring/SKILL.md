# 文档编写器

针对本项目的文档编写与维护技能，帮助 NPC 生成、更新、规范化项目文档。

## 适用场景

- 更新 README（功能、架构、快速开始）
- 生成/维护操作手册（docs/）
- 编写接口文档与变更说明
- 生成 CHANGELOG / 发布说明
- PR 变更的文档同步

## 文档规范

### 1. README 规范
- 结构：项目简介 → 功能特性 → 快速开始 → 架构说明 → 文档索引 → 许可证
- 技术栈、环境要求、安装步骤需准确
- 示例代码可运行
- 中文为主，术语与英文对应

### 2. 操作手册规范
- 面向用户，步骤式描述，可操作性
- 含截图 / 图表示例
- 错误处理与 FAQ 章节
- 版本更新后同步修订

### 3. 接口文档规范
- 每个接口：URL、方法、请求参数、响应结构、错误码
- 响应结构统一 `{code, message, data}`
- 与 `docs/api_mapping.md` 保持一致
- 标注鉴权要求

### 4. CHANGELOG 规范
- 基于语义化版本（SemVer）：`MAJOR.MINOR.PATCH`
- 按版本分组，`### Added / Changed / Fixed / Removed`
- 每条记录关联 Issue/PR 编号
- 当前版本对应 PR 合并后即时更新

## 编写流程

1. 收集变更信息（PR diff、Issue 描述、代码改动）
2. 分析影响面（新功能 / 修复 / 破坏性变更）
3. 按对应规范编写 / 更新文档
4. 交叉核对：技术栈、命令、路径与代码一致
5. 补充文档索引链接

## 项目约定

- README 已有文档索引列表，新增文档需同步更新入口
- `docs/` 目录存放操作手册与技术文档
- 接口映射以 `docs/api_mapping.md` 为权威源
- 平台实用技巧文档位于 `docs/平台实用技巧.md`

## ✅ 验收标准

- [ ] 文档中的命令、路径、参数名与代码实际一致（已实跑或 grep 核对）
- [ ] 新增文档已同步到 README 的文档索引
- [ ] 覆盖率、阈值等易变数字与 `.cnb.yml` / 脚本实际值一致
- [ ] 代码示例可直接复制执行，不含占位未说明的内容
- [ ] 术语与已有文档统一，未自造新词
